## ✅ 파티 시스템 TaskList

### 1. 📁 기초 구조 설계

* [ ] `Party` 클래스 및 `PartyManager` 싱글톤 설계
* [ ] `Player` 객체에 `PartyId` or `PartyRef` 참조 필드 추가
* [ ] 파티 멤버 정보 구조 (`PartyMemberInfo`) 정의

---

### 2. 🖧 서버: 파티 기능 구현

#### 파티 생성 & 초대

* [ ] 파티 생성 요청 처리 (`C_PARTY_CREATE` or 초대 시 자동 생성)
* [ ] 초대 요청 처리 (`C_PARTY_INVITE`)
* [ ] 초대 수락/거절 처리 (`C_PARTY_INVITE_ACCEPT` / `C_PARTY_INVITE_DECLINE`)
* [ ] 파티 가입 처리 및 전파 (`S_PARTY_MEMBER_JOINED`)

#### 이탈 & 퇴장

* [ ] 자발적 파티 탈퇴 처리 (`C_PARTY_LEAVE`)
* [ ] 파티장에 의한 강제 퇴장 처리 (`C_PARTY_KICK`)
* [ ] 멤버 퇴장 전파 (`S_PARTY_MEMBER_LEFT`)

---

### 3. 🔄 서버: 상태 동기화

* [ ] 파티원 위치 정보 주기 업데이트
* [ ] 파티원 HP/MP 상태 주기 업데이트
* [ ] `S_PARTY_MEMBER_STATUS` 패킷 브로드캐스트 구현

---

### 4. ⚔️ 서버: 경험치 분배 로직

* [ ] 몬스터 처치 이벤트 후 파티 멤버 필터링 (파티 포함 여부, 온라인 여부)
* [ ] 처치자에게 110%, 나머지에게 10% EXP 분배
* [ ] 기존 경험치 시스템에 파티 분배 로직 삽입

---

### 5. 🖥 클라이언트 UI

* [ ] 좌측 파티 UI 레이아웃 설계
* [ ] 파티원 리스트 동기화 처리 (`S_PARTY_MEMBER_JOINED`, `S_PARTY_MEMBER_LEFT`)
* [ ] 파티원 HP/MP 표시 UI 구현
* [ ] 파티원 위치 미니맵 UI 구현

---

### 6. 🧪 테스트 시나리오 검증

* [ ] 경험치 분배 검증 (정확한 비율로 분배되는지)
