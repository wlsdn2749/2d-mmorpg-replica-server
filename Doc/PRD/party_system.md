# 🧾 파티 시스템 PRD (사냥 전용 간소화 버전)

## 1. 🎯 목적 (Purpose)

플레이어가 다른 유저와 협력하여 몬스터를 사냥하고, 경험치를 공유할 수 있는 경량화된 파티 시스템을 구현한다.  
전리품은 각자 루팅하며, 파티원 상태와 위치 정보는 좌측 UI에 표시되는 구조로 한다.

---

## 2. 📌 핵심 기능 (Key Features)

| 기능             | 설명 |
|------------------|------|
| 파티 생성        | 플레이어가 새로운 파티 생성 가능 |
| 파티 초대 및 수락 | 파티장이 다른 유저를 초대, 유저가 수락 시 가입 |
| 파티 탈퇴        | 플레이어가 언제든 파티에서 나갈 수 있음 |
| 파티 강제 퇴장   | 파티장이 특정 파티원을 강제 퇴장시킴 |
| HP 동기화        | 파티원들의 체력 상태를 2초 주기로 UI에 표시 |
| 경험치 분배      | 처치자는 110% 획득, 나머지 파티원들은 각각 10% 획득 |
| 최대 인원 제한   | 파티는 최대 4명까지 구성 가능 |

---

## 3. 🧠 서버 처리 흐름 (Flow Summary)

- 초대 요청
  - C → S: 파티 초대 요청
  - S → C: 초대 알림
  - C → S: 초대 수락 또는 거절
  - S → 파티 전원: 새 멤버 정보 전파

- 이탈/추방 처리
  - C → S: 자발적 이탈 요청
  - S → 파티 전원: 해당 멤버 탈퇴 알림
  - 또는 C → S: 강제 퇴장 요청 (리더만 가능)

---

## 4. 📤 동기화 정보 (Sync Details)

- 상태 동기화: HP/MaxHP/Level 정보를 2초 주기로 파티원들에게 브로드캐스트
- 업데이트 타입: 멤버 가입/탈퇴/해체/상태 변경 시 각각 구분하여 전송
- 온라인 멤버만: 접속 중인 파티원에게만 정보 전송

---

## 5. ⚔️ 경험치 분배 방식 (EXP Distribution)

- 몬스터 처치 시:
  - 처치자: 100% 기본 경험치 + 10% 추가 보너스 = 총 110%
  - 그 외 파티원들: 각각 10% 획득
- 분배 조건:
  - 파티에 속해 있을 것
  - 온라인 상태일 것

---

## 6. 🧪 테스트 시나리오 (Test Scenarios)

| 시나리오 | 예상 결과 |
|----------|-----------|
| A가 파티 생성 후 B를 초대, B가 수락 | A와 B가 동일 파티에 소속됨 |
| B가 몬스터 처치 | B는 110% 경험치, A는 10% 경험치 획득 |
| C가 파티에 참여한 후 D가 몬스터 처치 | D는 110%, A/B/C는 각각 10% |
| A가 파티 탈퇴 | A는 더 이상 공유 경험치를 받지 않음 |
| A가 B를 강제 퇴장 | B는 파티에서 제거되며 경험치 공유 대상 아님 |

---

## 7. 🔐 제약사항 (Constraints)

- 최대 파티 인원 수: 4명
- 파티원 여부와 무관하게 전리품은 각자 루팅
- 파티장 이전 기능은 없음 (파티장 탈퇴 시 파티 자동 해체)
- 파티 데이터는 메모리에만 저장 (서버 재시작 시 모든 파티 해체)
- 위치 정보 동기화는 미지원 (클라이언트 UI 구현 시 고려 가능)
- MP(마나) 동기화는 미지원 (현재 HP만 동기화)
- 드랍 분배 규칙 없음
- 크로스 룸 초대 가능 (다른 Room에 있는 플레이어도 초대 가능)
