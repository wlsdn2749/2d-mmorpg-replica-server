### **인벤토리 조회 응답**

- 설명: 서버가 클라이언트의 인벤토리 조회 요청에 대해 전체 인벤토리 정보를 응답하는 패킷
- 입력: `C_InventoryRequest`에 대한 응답
- 처리 로직:
    - 플레이어의 전체 인벤토리 슬롯 정보를 수집
    - 일반 슬롯(0-29)과 퀵 슬롯(30-39)을 구분하여 데이터 구성
    - 빈 슬롯은 제외하고 아이템이 있는 슬롯만 포함
    - `InventorySlotInfo` 배열로 슬롯 정보 전송
- 출력: 클라이언트가 인벤토리 UI 업데이트
- 데이터 구조: `InventorySlotInfo` (슬롯 인덱스, 아이템ID, 수량, 퀵슬롯 여부)
