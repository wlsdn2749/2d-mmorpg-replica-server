### **인벤토리 조회 요청**

- 설명: 클라이언트가 서버에 자신의 인벤토리 정보를 요청하는 패킷
- 입력: `C_InventoryRequest`
- 처리 로직:
    - 클라이언트 세션에서 플레이어 정보 확인
    - 플레이어의 인벤토리 데이터를 데이터베이스에서 조회
    - 일반 슬롯(0-29)과 퀵 슬롯(30-39) 정보를 포함하여 응답 생성
    - 각 슬롯의 아이템ID, 수량, 퀵슬롯 여부를 포함
- 출력: `S_InventoryReply`
- 데이터 구조: `Player` 테이블의 인벤토리 관련 필드, `ItemConfig.json`
