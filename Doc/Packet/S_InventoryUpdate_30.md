### **인벤토리 업데이트 브로드캐스트**

- 설명: 서버가 플레이어의 인벤토리가 변경되었을 때 변경된 슬롯 정보만을 클라이언트에 브로드캐스트하는 패킷
- 입력: 인벤토리 변경 이벤트 (아이템 사용, 획득, 이동 등)
- 처리 로직:
    - 인벤토리 변경이 발생한 슬롯들만 수집
    - 변경된 슬롯의 최신 상태 정보 구성
    - 빈 슬롯이 된 경우 count=0으로 전송
    - 아이템이 추가/변경된 경우 현재 수량과 아이템ID 전송
    - 동일 룸의 해당 플레이어에게만 전송 (본인용)
- 출력: 클라이언트가 변경된 슬롯만 UI 업데이트
- 데이터 구조: `InventorySlotInfo` 배열 (변경된 슬롯들만)
