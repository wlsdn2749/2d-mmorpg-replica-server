### **아이템 사용 요청**

- 설명: 클라이언트가 인벤토리의 특정 슬롯에 있는 아이템 사용을 서버에 요청하는 패킷
- 입력: `C_ItemUseRequest` (slotIndex)
- 처리 로직:
    - 요청된 슬롯 인덱스의 유효성 검증 (0-39 범위)
    - 해당 슬롯에 아이템 존재 여부 확인
    - 아이템 타입이 소비 가능한지 검증 (`ITEM_TYPE_CONSUMABLE`)
    - 아이템 효과 적용 (HP 회복 등)
    - 아이템 수량 감소 또는 슬롯에서 제거
    - 인벤토리 변경 사항을 데이터베이스에 저장
- 출력: `S_ItemUseReply`, `S_InventoryUpdate` (브로드캐스트)
- 데이터 구조: `Player` 테이블 인벤토리, `ItemConfig.json` 아이템 정보
