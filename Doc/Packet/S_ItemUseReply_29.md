### **아이템 사용 응답**

- 설명: 서버가 클라이언트의 아이템 사용 요청에 대한 성공/실패 결과를 응답하는 패킷
- 입력: `C_ItemUseRequest`에 대한 응답
- 처리 로직:
    - 아이템 사용 처리 결과에 따라 success 플래그 설정
    - 실패한 경우 구체적인 오류 메시지 포함
        - "빈 슬롯입니다"
        - "사용할 수 없는 아이템입니다"
        - "잘못된 슬롯 번호입니다"
    - 성공한 경우 빈 오류 메시지
- 출력: 클라이언트가 결과에 따른 UI 피드백 표시
- 데이터 구조: `boolean success`, `string errorMessage`
